# Паттерн онлайн-записи

Самый важный сценарий платформы. Сегодня простаивает 51 % ёмкости центра,
и в базе только 28 % клиентов имеют телефон. Запись решает обе задачи сразу:
продаёт пустой слот и собирает контакт.

## Правила, из которых всё следует

1. **Без регистрации.** Имя и телефон — всё. Пароль, почта, подтверждение по e-mail
   отсекают половину аудитории.
2. **Мастер выбирается до времени.** Данные показывают: клиент идёт к человеку.
   Порядок «мастер → время» даёт выше конверсию и выравнивает загрузку кабинетов.
3. **Не больше четырёх шагов.** Пятый шаг — потеря.
4. **Телефон обязателен, согласие — отдельно.** Без согласия на связь повторная
   продажа курса юридически невозможна.
5. **Запасной путь всегда виден.** Номер центра и Telegram — на каждом шаге.

## Поток

```
┌─ Шаг 1 ─────────┐   ┌─ Шаг 2 ──────────┐   ┌─ Шаг 3 ─────────┐   ┌─ Шаг 4 ───────┐
│ Что вам нужно   │ → │ Мастер           │ → │ Дата и время    │ → │ Контакт       │
│                 │   │                  │   │                 │   │               │
│ ○ Спина и шея   │   │ [карточка] Нигина│   │ Пн Вт Ср Чт Пт Сб│  │ Имя           │
│ ○ Общий курс    │   │ [карточка] Фируза│   │ 11:00 ✓ 12:30    │  │ Телефон       │
│ ○ После нагрузок│   │ [карточка] Бахром│   │ 14:00   15:30    │  │ ☑ согласие    │
│ ○ Детям         │   │ ○ Любой свободный│   │ 17:00   18:30    │  │ [Записаться]  │
│                 │   │                  │   │                 │   │               │
│ ○ 1 сеанс       │   │                  │   │ 3 слота свободно │  │               │
│ ● Курс 10       │   │                  │   │ на этой неделе   │  │               │
└─────────────────┘   └──────────────────┘   └─────────────────┘   └───────────────┘
        │                      │                      │                     │
        └──────────── назад на любой шаг без потери данных ─────────────────┘
```

### Шаг 1 — Что вам нужно

- Четыре программы + выбор «курс или один сеанс».
- **Курс выбран по умолчанию** — это продукт центра. Один сеанс остаётся доступен,
  но не является опцией по умолчанию.
- Под каждой программой — длительность и цена курса целиком, не «от».
- Детская программа помечена: «по направлению врача», бейдж `child`.

### Шаг 2 — Мастер

- Карточки мастеров (`TherapistCard`) с ближайшим свободным слотом.
- Вариант «Любой свободный» — последним, не первым: он снижает привязку к мастеру,
  но нужен тем, кому срочно.
- Если у мастера нет слотов на две недели — карточка показывает «Запись с 7 ноября»,
  а не исчезает.

### Шаг 3 — Дата и время

- Неделя целиком, переключение по неделям стрелками.
- Воскресенье **показано выключенным** с подписью «выходной», а не пропущено.
- Слоты — компонент `SlotChip`, занятые видны серыми.
- Для курса: система предлагает **повторяющееся время** — «каждый будний день в 11:00
  до 2 ноября». Это и есть курс: одно время на весь курс, как в учётной книге центра.
- Если выбранного времени нет на весь курс — показывается, в какие дни оно занято,
  и предлагается ближайшая альтернатива.

### Шаг 4 — Контакт

Минимальная форма:

| Поле | Обязательно | Примечание |
|---|---|---|
| Имя | да | одно поле, не «фамилия/имя/отчество» |
| Телефон | да | маска `+992 __ ___ __ __` |
| Комментарий | нет | «что беспокоит» — 200 знаков |
| Согласие на обработку данных | да | чекбокс со ссылкой на документ |
| Согласие на сообщения о записи и курсе | да, отдельно | без него нельзя напоминать и продлевать |

Третий чекбокс «реклама и акции» — **не добавляется**. Он снижает конверсию
и не нужен: напоминания о курсе покрываются вторым согласием.

## Подтверждение

После отправки — экран, а не всплывашка:

```
        ✓  Вы записаны

        Курс «Спина и шея», 10 сеансов
        Мастер: Нигина Саидова
        Каждый будний день в 11:00
        с 27 октября по 7 ноября

        Кабинет: Нам
        Адрес: ...

        [Добавить в календарь]   [Открыть в Telegram]

        Администратор позвонит в течение часа,
        чтобы подтвердить первый сеанс.
```

Обязательно: ссылка «Добавить в календарь» (`.ics` со всеми сеансами курса)
и дублирование в Telegram-бот, если клиент им пользуется.

## Напоминания

| Когда | Канал | Текст (сокращённо) |
|---|---|---|
| Сразу | SMS | «Вы записаны: 27.10, 11:00, мастер Нигина. ОРОМ» |
| За сутки | SMS / Telegram | «Завтра в 11:00 ждём вас. Перенести: ссылка» |
| За 2 часа | Telegram | «Сегодня в 11:00. Адрес: ...» |
| После 8-го сеанса | Telegram | «Остался 1 сеанс курса. Продлить?» |
| Через 14 дней после курса | SMS | «Как спина? Новый курс со скидкой на закрепление» |

Напоминание за сутки — самый дешёвый способ снизить неявку. Перенос из напоминания
в один клик обязателен: перенесённый сеанс лучше пустого.

## Обработка нештатных ситуаций

| Ситуация | Поведение |
|---|---|
| Слот заняли, пока клиент заполнял форму | честное сообщение + 3 ближайшие альтернативы, данные формы сохранены |
| Нет связи | форма сохраняется локально, повтор отправки автоматически |
| Клиент уже есть в базе по телефону | подтягивается имя, предлагается продолжить как существующий клиент |
| Запись на занятое время у «любого мастера» | автоматически подставляется свободный кабинет |
| Запись в воскресенье по прямой ссылке | редирект на понедельник с пояснением |

## Метрики воронки

| Событие | Что показывает |
|---|---|
| `booking_started` | открыт шаг 1 |
| `step_completed:1..4` | где отваливаются |
| `slot_selected` | выбран слот (ключевой момент) |
| `booking_completed` | запись создана |
| `booking_abandoned` | ушёл со страницы без записи — с указанием шага |
| `phone_click` | предпочёл позвонить: значит, форма сложна |

**Целевая конверсия:** от открытия шага 1 до записи — не ниже 35 %.
Ниже 20 % — форма неисправна, а не аудитория плохая.

## Доступность

- Весь поток проходится с клавиатуры, включая выбор слота (стрелки + Enter).
- Шаги объявляются скринридером: `aria-live="polite"`, «Шаг 3 из 4, дата и время».
- Слот имеет полную подпись: `aria-label="11:00, мастер Нигина, свободно"`.
- Ошибки связаны с полями через `aria-describedby`, фокус переходит на первое с ошибкой.
- Таймер удержания слота, если он есть, — не меньше 10 минут и с возможностью продлить.
