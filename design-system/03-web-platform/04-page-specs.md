# Спецификации страниц

Для каждой страницы: цель, блоки сверху вниз, токены, тексты. Раскладки даны
в десктопном виде; мобильный порядок указан отдельно, где он отличается.

---

## Главная

**Цель:** перевести на запись. Всё остальное — вторично.

```
┌────────────────────────────────────────────────────────────────┐
│ [лого]  Курсы  Мастера  Компаниям  Сертификат  О центре  RU▾  [Записаться] │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  ВОССТАНОВЛЕНИЕ                   ┌──────────────────────────┐ │
│  Курс из десяти сеансов           │                          │ │
│  за три недели                    │   фото: руки мастера     │ │
│                                   │   на спине, крупно       │ │
│  Один мастер ведёт курс от        │   radius-xl              │ │
│  первого до последнего сеанса.    │                          │ │
│  Время закреплено на весь курс.   └──────────────────────────┘ │
│                                                                │
│  [Выбрать время]  [Как проходит курс]                          │
│                                                                │
│  11:00 · 12:30 · 14:00 · 15:30 · 17:00 · 18:30   Пн–Сб        │
├────────────────────────────────────────────────────────────────┤
│  ближайшие свободные слоты · 3 карточки · live из расписания    │
├────────────────────────────────────────────────────────────────┤
│  Четыре программы · 4 карточки                                 │
├────────────────────────────────────────────────────────────────┤
│  Мастера · 3 карточки TherapistCard                            │
├────────────────────────────────────────────────────────────────┤
│  Как проходит курс · 4 шага горизонтально                      │
├────────────────────────────────────────────────────────────────┤
│  Компаниям · тёмный блок forest-800 · [Запросить предложение]  │
├────────────────────────────────────────────────────────────────┤
│  Отзывы · 3 карточки (только с письменным согласием)           │
├────────────────────────────────────────────────────────────────┤
│  Подвал                                                         │
└────────────────────────────────────────────────────────────────┘
```

| Блок | Токены |
|---|---|
| Первый экран | фон `--bg-page`, высота 640 px, 7 колонок текст + 5 фото |
| Надзаголовок | `--text-overline`, `--text-accent` |
| Заголовок | `--text-display-2`, `--color-forest-800` |
| Лид | `--text-body-lg`, `--text-secondary`, ширина до 480 px |
| Строка слотов | `--text-mono`, `--text-muted` |
| Блок «Компаниям» | фон `--bg-inverse`, текст `--text-on-inverse` |
| Отступ между блоками | `--space-24` десктоп, `--space-16` мобильный |

**Тексты первого экрана**

| Язык | Надзаголовок | Заголовок | Лид |
|---|---|---|---|
| RU | ВОССТАНОВЛЕНИЕ | Курс из десяти сеансов за три недели | Один мастер ведёт курс от первого до последнего сеанса. Время закреплено на весь курс. |
| TJ | БАРҚАРОРСОЗӢ | Курси даҳсеансӣ дар се ҳафта | Як устод курсро аз сеанси аввал то охирин мебарад. Вақт барои тамоми курс мустаҳкам карда мешавад. |
| EN | RECOVERY | A ten-session course over three weeks | One therapist leads the course from first session to last. Your time slot is fixed for the whole course. |

**Мобильный порядок:** заголовок → фото → лид → кнопка → слоты → программы →
мастера → как проходит → компаниям → подвал.

## Курс (например, «Спина и шея»)

**Цель:** записаться именно на этот курс.

Блоки:

1. Хлебных крошек нет. Заголовок курса `--text-h1` + бейдж программы.
2. Параметры курса — таблица из четырёх строк: сеансов, длительность сеанса,
   срок курса, цена курса. **Цена курса целиком**, рядом мелко — «за сеанс выходит …».
3. Кому подходит — список из 4–6 пунктов, без медицинских диагнозов.
4. Как проходит сеанс — 3 абзаца, честно: что делают, что чувствуешь, что после.
5. Противопоказания — отдельный блок `Alert` со `--status-info`. Обязателен.
6. Мастера, ведущие этот курс.
7. Виджет записи, предзаполненный этим курсом.
8. FAQ по курсу — аккордеон, 5 вопросов.

**Запрещено на странице курса:** слова «лечение», «излечим», «гарантируем результат»,
«медицинская процедура», обещание избавления от боли.

## Мастера

**Цель:** выбрать мастера и записаться. Решает перекос загрузки 34 % против 71,6 %.

- Сетка карточек: 3 колонки десктоп, 2 планшет, 1 мобильный.
- У каждой карточки — ближайший свободный слот из расписания.
- Фильтр по программе — чипы над сеткой.
- Сортировка по умолчанию: **сначала тот, у кого больше свободных слотов.**
  Это выравнивает загрузку кабинетов автоматически, не навязывая выбор клиенту.

## Запись

**Цель:** завершённая бронь с контактом. Больше целей нет.

- Шапка сокращённая: логотип + телефон + переключатель языка. Меню убрано.
- Никаких других блоков на странице: ни отзывов, ни «популярных курсов».
- Прогресс-индикатор «Шаг 2 из 4» сверху.
- Телефон центра и Telegram — в правом верхнем углу на всех шагах.
- Подробности — [`03-booking-pattern.md`](03-booking-pattern.md).

## Компаниям

**Цель:** заявка на корпоративный пакет. Аудитория — HR и руководитель.

Блоки:

1. Заголовок + лид на языке выгоды работодателя: меньше больничных,
   меньше жалоб на спину у офисных сотрудников.
2. Два пакета карточками: **40 сеансов** и **80 сеансов** — ровно те, что
   закупают сегодняшние клиенты центра. Третья карточка — «свой объём».
3. Что получает компания — четыре пункта с иконками:
   закреплённое время, учёт явки, ежемесячный отчёт, один счёт.
4. **Образец отчёта** — изображение страницы отчёта с кнопкой «Посмотреть пример».
   Это главный аргумент: компания покупает не массаж, а управляемость.
5. Как устроено сопровождение — 4 шага.
6. Форма заявки: компания, контактное лицо, телефон, число сотрудников, комментарий.
7. Кнопка «Скачать презентацию пакета» (PDF из
   [`05-documents/04-sample-corporate-offer.md`](../05-documents/04-sample-corporate-offer.md)).

Фон страницы чередуется: `--bg-page` → `--bg-inverse` → `--bg-page`.
Тёмный блок — там, где цифры пакетов.

## Сертификат

**Цель:** покупка. Сезонная страница — Навруз, 8 Марта, Иди Рамазон, Новый год.

- Первый экран: изображение сертификата крупно, рамка `--border-strong`, бейдж `certificate`.
- Три номинала: курс 5, курс 10, свободная сумма.
- Чётко: **срок действия 6 месяцев**, получатель сам выбирает мастера и время.
- Способ получения: печатный бланк в центре или PDF на телефон.
- Форма: от кого, кому, номинал, способ, телефон покупателя.
- Образец — [`05-documents/02-sample-certificate.md`](../05-documents/02-sample-certificate.md).

## Личный кабинет — Мой курс

**Цель:** клиент видит прогресс и не бросает курс на середине.

```
┌──────────────────────────────────────────────┐
│ Здравствуйте, Мануш                          │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ CourseProgress: 7 из 10                  │ │
│ │ ● ● ● ● ● ● ● ○ ○ ○                      │ │
│ │ Следующий: пт, 24 окт, 11:00 · Нигина    │ │
│ │ [Перенести]  [Отменить]                  │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ История сеансов · таблица                    │
│ Мои сертификаты                              │
│ Контакты и согласия                          │
└──────────────────────────────────────────────┘
```

- При остатке ≤ 2 сеансов сверху появляется блок «Продлить курс» с `--status-warning`.
- Перенос — максимум в два клика, доступные слоты сразу в карточке.
- Отмена позже чем за 4 часа показывает правило центра, но не блокирует кнопку.

## Контакты

- Карта во всю ширину, высота 420 px, метка центра.
- Часы работы таблицей, **воскресенье выделено как выходной**.
- Телефон — кликабельный, крупный, `--text-h3`.
- Как добраться: ориентиры словами, а не только координаты.
- Кнопки «Построить маршрут» и «Написать в Telegram».

## Общие требования к любой странице

- [ ] Одна главная цель и одна акцентная кнопка.
- [ ] `<title>` и `<h1>` различаются и несут смысл.
- [ ] Первый экран понятен без прокрутки на экране 360 × 640.
- [ ] Все тексты есть на трёх языках, макет не ломается на самом длинном.
- [ ] Контрасты проверены по таблицам из [`03-color.md`](../01-foundations/03-color.md).
- [ ] Страница читается при отключённых изображениях.
- [ ] Телефон центра доступен с любой страницы в один клик.
