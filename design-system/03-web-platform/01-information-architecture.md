# Архитектура веб-платформы

## Три продукта в одной платформе

| Продукт | Кто пользуется | Главная задача |
|---|---|---|
| **Публичный сайт** | частный клиент, покупатель сертификата, родитель | понять услугу и записаться |
| **Личный кабинет** | клиент с активным курсом | видеть прогресс курса и переносить сеансы |
| **Админ-панель** | администратор, мастер, руководитель | вести расписание, учёт, отчёты |

Админ-панель заменяет текущую учётную книгу: три листа Excel превращаются
в три экрана — расписание, клиенты, загрузка.

## Навигация публичного сайта

**Шапка (десктоп)**

```
[лого]   Курсы   Мастера   Компаниям   Сертификат   О центре      [RU ▾]   [Записаться]
```

- Пунктов меню — максимум шесть. Седьмой убирается в «О центре».
- Кнопка «Записаться» — единственная акцентная на всей странице, цвет `action-accent`.
- Переключатель языка — RU / ТҶ / EN, всегда виден, никогда не прячется в подвал.

**Шапка (мобильный)**

```
[лого]                                              [RU ▾]  [☰]
──────────────────────────────────────────────────────────────
                 [Записаться]  — липкая кнопка внизу экрана
```

Кнопка записи на мобильном закреплена внизу и видна всегда. Это главный элемент
сайта: 48,8 % ёмкости центра пустует, и каждый лишний клик до записи стоит сеанса.

## Приоритет целей по страницам

У каждой страницы ровно одна главная цель. Если целей две — страница делится.

| Страница | Главная цель | Вторичная |
|---|---|---|
| Главная | перейти к записи | понять, что это курс |
| Курс | выбрать курс и записаться | понять, сколько сеансов и сколько стоит |
| Мастера | выбрать мастера | записаться к нему |
| Запись | завершить бронь с контактом | — (других целей нет) |
| Компаниям | оставить заявку | скачать презентацию пакета |
| Сертификат | купить | понять срок действия |
| Контакты | построить маршрут | позвонить |

## Требования к URL и локализации

- Язык в пути: `/ru/...`, `/tg/...`, `/en/...`. Русский — по умолчанию, без редиректа
  с корня на `/ru/`.
- Слаги латиницей и на английском: `/tg/booking`, а не `/tg/сабтном`. Так ссылки
  переживают пересылку в мессенджерах.
- `hreflang` на каждой странице для трёх языков плюс `x-default` → русская версия.

## Технические требования

| Требование | Значение |
|---|---|
| LCP | < 2,5 с на 3G (аудитория часто на мобильном интернете) |
| Вес первого экрана | < 350 КБ, включая шрифты |
| Шрифты | `woff2`, подмножество кириллицы + таджикских глифов, `font-display: swap` |
| Работа без JS | страницы читаются; форма записи требует JS, но показывает телефон как запасной путь |
| Запись без регистрации | обязательна: имя + телефон, не более |
| Аналитика целей | `booking_started`, `slot_selected`, `booking_completed`, `phone_click`, `corporate_request` |
