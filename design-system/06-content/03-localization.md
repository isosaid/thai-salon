# Локализация

Три языка — не «перевод основного», а три равноправные версии. Клиентура центра
двуязычна: в базе рядом «Азизов Хуршед», «Саидова Нигина» и
«Селецкая Ирина», а названия групп записаны и кириллицей, и латиницей.

|---|---|---|---|
| Сайт | русский | таджикский | английский |

## Таджикские глифы — техническое требование

Таджикская кириллица содержит шесть букв сверх русской: **ғ ӣ қ ӯ ҳ ҷ**
(и заглавные **Ғ Ӣ Қ Ӯ Ҳ Ҷ**).

### Проверка шрифта

Перед утверждением шрифта набрать строку:

```
Ғафурӣ Қаҳҳор ҷӯйбор ҳавз ӯзбек ӣ — ҒӢҚӮҲҶ
Маркази массаж ва барқарорсозӣ
```

Если хотя бы один знак отрисован другим шрифтом (видно по толщине или ширине) —
шрифт не подходит. Подстановки не бывает «почти незаметной».

Проверенные: PT Serif, PT Sans, Inter, Noto Serif, Noto Sans.
Не подходят: Playfair Display, Cormorant, Montserrat.

### Веб-шрифты

Подмножество шрифта (subset) должно включать блоки Cyrillic **и**
Cyrillic Extended-A/B — иначе таджикские буквы подгрузятся отдельным
запросом или не подгрузятся вовсе.

```css
@font-face {
  font-family: "PT Serif";
  src: url("pt-serif-subset.woff2") format("woff2");
  unicode-range: U+0000-00FF, U+0400-045F, U+0490-04FF, U+2010-2027;
  font-display: swap;
}
```

Диапазон `U+0490-04FF` — это и есть таджикские буквы. Без него система ломается.

## Длина строки

| Язык | Относительно русского |
|---|---|
| Таджикский | +10…15 % |
| Английский | −10…20 % |

Макет собирается по **самой длинной** версии. Практический запас:

| Элемент | Запас |
|---|---|
| Кнопка | +25 % ширины или перенос на две строки |
| Пункт меню | фиксированная ширина по длинному языку |
| Заголовок | +15 % высоты блока |
| Подпись поля формы | +20 % |
| Ячейка таблицы | перенос разрешён, обрезка — нет |

## Правила набора по языкам

### Русский и таджикский
- Кавычки «ёлочки», вложенные „лапки“.
- Автопереносы включены: `lang="ru"` / `lang="tg"` + `hyphens: auto`.
- Длинное тире `—` с пробелами.
- Неразрывные пробелы: `10 сеансов`, `1,5 ч`, `г. Душанбе`.

### Английский
- Кавычки “curly”.
- Переносы выключены.
- Тире — em dash без пробелов или en dash с пробелами, но единообразно.
- Время в 24-часовом формате, как в остальных версиях: `11:00`, не `11 AM`.

## Что не переводится

| Остаётся как есть | Почему |
|---|---|
| ОРОМ / OROM | название бренда |
| Имена мастеров | транслитерация допустима, перевод — нет |
| Названия кабинетов: Нам, Ели, НОЙ | внутренние обозначения |
| Названия компаний-клиентов | юридические наименования |
| Телефон, домен, адрес почты | технические данные |
| Время слотов | числа одинаковы во всех версиях |

## Имена клиентов

В базе соседствуют две традиции: таджикская (Азизов Хуршед,
Шарипова Зарина) и русская (Селецкая Ирина, Ахмедова Светлана).

- **Одно поле «Имя»** в форме записи, не три поля «фамилия / имя / отчество».
  Клиент пишет так, как привык.
- В интерфейсе и документах имя выводится **как введено**, без
  автоматического переформатирования и без приведения к «Фамилия И. О.».
- Сортировка — по введённой строке, с учётом таджикского алфавита.
- В публичной части чужое имя не показывается никогда.

## Телефоны

Формат: `+992 93 172 77 77` — код страны, оператор, затем три группы.
Маска ввода `+992 __ ___ __ __`. В базе хранится без пробелов: `992931727777`.
В документах и макетах — с пробелами и неразрывными пробелами внутри групп.

## Даты

| Контекст | Формат |
|---|---|
| Документы | `23.10.2026` |
| Текст на русском | `23 октября 2026` |
| Текст на таджикском | `23 октябри соли 2026` |
| Интерфейс, короткая форма | `23.10` |
| Технические поля, имена файлов | `2026-10-23` |

Дни недели в интерфейсе сокращаются: `Пн Вт Ср Чт Пт Сб Вс` /
`Дш Сш Чш Пш Ҷм Шн Яш`.

## Процесс перевода

1. Текст пишется на русском и попадает в
   [`02-copy-library-ru-tj-en.md`](02-copy-library-ru-tj-en.md).
2. Таджикская версия делается носителем языка, **не машинным переводом** —
   машинный перевод на таджикский регулярно ошибается в падежах и изафете.
3. Английская версия — для корпоративной и международной аудитории.
4. Все три версии проверяются в макете, а не в таблице: в макете видно,
   что не помещается.

## Чек-лист локализации

- [ ] Шрифт прошёл проверку глифов `ҒӢҚӮҲҶ`.
- [ ] Subset шрифта включает `U+0490-04FF`.
- [ ] Макет проверен на самой длинной языковой версии.
- [ ] `lang` проставлен для каждого языкового блока.
- [ ] Числа, время и телефоны одинаковы во всех версиях.
- [ ] Имена не переформатированы автоматически.
- [ ] Таджикский текст вычитан носителем.
- [ ] Переключатель языка виден и не спрятан в бургер.
