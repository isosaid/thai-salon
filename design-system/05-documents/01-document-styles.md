# Стили документов

## Общие параметры

| Параметр | Значение |
|---|---|
| Формат | A4 — 210 × 297 мм; сертификат — A5 альбомный 210 × 148 мм |
| Поля | 20 мм слева и справа, 20 сверху, 25 снизу; с таблицей — 15 мм по бокам |
| Фон | белый для официальных документов, `--color-cream` для маркетинговых |
| Шрифт заголовков | PT Serif Bold |
| Шрифт текста | PT Serif Regular (документы) или Inter (отчёты и таблицы) |
| Шрифт цифр | JetBrains Mono в таблицах, всегда `tabular-nums` |
| Основной кегль | 10–11 pt, интерлиньяж 1,4 |
| Цвет текста | 100 % K; акценты — `--color-forest-800` |
| Радиусы | 0 — документы не скругляются |
| Тени | нет; вместо них линии `--border-default` |

## Шапка документа

```
[знак 16 мм]  ОРОМ                             Документ № 10-2026/АВ
              ЦЕНТР МАССАЖА И ВОССТАНОВЛЕНИЯ   от 31.10.2026
──────────────────────────────────────────────────────────────────
```

- Знак слева, название PT Serif Bold 14 pt, трекинг +2,5.
- Дескриптор под названием — 5,5 pt, `--text-muted`, в верхнем регистре.
- Номер и дата — справа, выключка вправо, 9 pt.
- Линия под шапкой — 1,5 pt `--color-forest-800`, во всю ширину полосы набора.

## Подвал документа

Одна строка 7 pt `--text-muted`:

```
Центр массажа и восстановления «ОРОМ» · Душанбе · +992 93 172 77 77 · orom.tj
```

На многостраничных документах добавляется нумерация справа: `с. 2 из 4`.

## Таблицы в документах

| Элемент | Значение |
|---|---|
| Шапка таблицы | фон `--color-sand-300`, 6,5 pt, верхний регистр, трекинг +0,4 |
| Строка | высота 17–18 px (≈4,5 мм), текст 7,5–8 pt |
| Зебра | нечётные строки `--color-cream` |
| Линии | 0,5 pt `--color-line` только горизонтальные; вертикальных нет |
| Итоговая строка | фон `--color-forest-100`, полужирный |
| Числа | выключка вправо, моноширинный |
| Статус «завершено» | `--status-success` + галочка, не только цвет |

Вертикальные линии в таблицах не используются: они утяжеляют документ и мешают
чтению строк — главного направления в отчёте.

## Иерархия документа

| Уровень | Стиль |
|---|---|
| Название документа | PT Serif Bold 17 pt, `--color-ink-900` |
| Подзаголовок с реквизитами | Inter 10 pt, `--text-secondary` |
| Раздел | PT Serif Bold 12 pt, отступ сверху 8 мм |
| Текст | 10 pt / 14 pt |
| Список | тире `—`, не маркеры-точки |
| Сноска | 7,5 pt, `--text-muted` |

## Подписи

```
________________________              ________________________
Администратор центра                  Представитель компании
```

Линия 0,8 pt, длина 50 мм, подпись должности 7,2 pt под линией.
Место под печать — окружность Ø 20 мм, пунктир `--color-sand-500`, **только
на документах, где печать действительно ставится.**

## Экспорт

| Параметр | Значение |
|---|---|
| Формат | PDF/A-1b для архива, обычный PDF для отправки |
| Цвет | CMYK для печати, sRGB для отправки по почте |
| Шрифты | встроены (PT Serif и Inter это допускают) |
| Разрешение изображений | 300 dpi |
| Имя файла | `OROM_тип_контрагент_ГГГГ-ММ.pdf`, например `OROM_otchet_avesto_2026-10.pdf` |

## Язык документов

| Документ | Язык |
|---|---|
| Договор, счёт, акт | русский (при необходимости — таджикский дубль отдельным файлом) |
| Отчёт для компании | русский |
| Сертификат | русский + таджикская строка |
| Карта курса для клиента | русский + таджикский |
| Корпоративное предложение | русский, для международных компаний — английский |

Двуязычный документ делается **двумя колонками или двумя файлами**, а не
чередованием строк: чередование нечитаемо.
