Текст в них задан системными шрифтами с фолбэком — после установки PT Serif
и Inter отрисовка совпадёт с описанной в системе.

## Чего здесь нет

Фотографий. Фотостиль описан в
[`01-foundations/07-photography.md`](../01-foundations/07-photography.md),
включая список обязательных кадров и промпты для генеративных изображений,
но саму съёмку нужно провести. До съёмки в макетах стоят плейсхолдеры
`--color-forest-100` с подписью, что за кадр сюда встанет.
