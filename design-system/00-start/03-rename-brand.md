# Переименование бренда

Название **ОРОМ** вынесено в токены, чтобы замена занимала одну операцию.

## Почему ОРОМ

- Тадж./перс. **ором** — покой, умиротворение, облегчение. Прямо называет результат услуги.
- Читается одинаково в трёх языках: **ОРОМ / Ором / OROM**. Не требует перевода.
- 4 буквы, две одинаковые гласные — узнаётся с расстояния, работает в иконке 32×32.
- Свободно от медицинских обещаний: это состояние, а не диагноз.

## Как заменить

### 1. Текст в файлах системы

```bash
# из корня архива
grep -rl 'ОРОМ\|OROM\|Ором' . | xargs sed -i 's/ОРОМ/НОВОЕ/g; s/OROM/NEWNAME/g; s/Ором/Новое/g'
```

### 2. Токены

| Токен | Значение сейчас | Где используется |
|---|---|---|
| `--brand-name-ru` | `ОРОМ` | заголовки, документы |
| `--brand-name-tj` | `ОРОМ` | таджикские версии |
| `--brand-name-en` | `OROM` | латиница, домен, e-mail |
| `--brand-legal-ru` | `Центр массажа и восстановления «ОРОМ»` | договоры, акты, счёт |
| `--brand-tagline-ru` | `Тело помнит заботу` | постеры, обложки |
| `--brand-tagline-tj` | `Бадан ғамхориро дар ёд дорад` | таджикские макеты |
| `--brand-tagline-en` | `The body remembers care` | английские макеты |
| `--brand-domain` | `orom.tj` | подпись в макетах, QR |

Правьте их в [`02-tokens/tokens.css`](../02-tokens/tokens.css) и
[`02-tokens/tokens.json`](../02-tokens/tokens.json).

### 3. Логотип

Логотип построен на типографике, а не на уникальном рисунке — замена названия
не ломает конструкцию. Правила пересборки — в
[`01-foundations/02-logo.md`](../01-foundations/02-logo.md), раздел «Если название меняется».
Файлы: [`assets/logo-lockup.svg`](../assets/logo-lockup.svg), [`assets/logo-mark.svg`](../assets/logo-mark.svg).

## Проверка нового названия

Перед заменой прогоните имя по чек-листу:

- [ ] Читается без ошибок на русском, таджикском и английском.
- [ ] Нет нежелательного значения в таджикском и узбекском.
- [ ] Домен `.tj` свободен; Instagram и Telegram-ник свободны.
- [ ] Нет действующего товарного знака в классе 44 (медицинские и косметические услуги) в РТ.
- [ ] Умещается в квадрат 32×32 px в виде монограммы и остаётся различимым.
- [ ] Не обещает лечения (иначе — требования к рекламе медицинских услуг).
- [ ] Произносится по телефону с первого раза без «повторите по буквам».
