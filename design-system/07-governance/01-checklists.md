# Чек-листы приёмки

Один общий чек-лист и несколько частных. Материал не публикуется,
пока общий чек-лист не пройден полностью.

## Общий чек-лист — для любого материала

### Бренд
- [ ] Логотип в правильной версии, охранное поле соблюдено, минимальный размер соблюдён.
- [ ] Цвета только из палитры, терракоты не больше 10 % площади.
- [ ] Шрифты только PT Serif / Inter / PT Sans / JetBrains Mono.
- [ ] Не больше двух гарнитур в макете.
- [ ] Материал проходит проверку «это ОРОМ?» из
      [`01-foundations/01-brand-platform.md`](../01-foundations/01-brand-platform.md).

### Содержание
- [ ] Говорит о курсе и результате, а не о разовой процедуре.
- [ ] Одно действие, один призыв.
- [ ] Нет медицинских обещаний.
- [ ] Нет срочности и давления.
- [ ] Нет превосходных степеней без подтверждения.
- [ ] Цена, если указана, — за курс целиком.

### Данные
- [ ] Слоты, даты и цифры — настоящие, сверены с расписанием сегодня.
- [ ] Телефон и домен проверены.
- [ ] QR-код проверен на реальном устройстве.

### Язык
- [ ] Текст вычитан носителем на каждом использованном языке.
- [ ] Макет не ломается на самой длинной языковой версии.
- [ ] Таджикские глифы отрисованы нужным шрифтом.

### Доступность
- [ ] Контраст проверен по таблицам из [`01-foundations/03-color.md`](../01-foundations/03-color.md).
- [ ] Смысл не передаётся только цветом.
- [ ] Текст на фото — на затемнении или плашке.

## Согласие на съёмку

Фото и видео клиента публикуются только с подписанным согласием.
Форма — один лист, выдаётся администратором:

```
СОГЛАСИЕ НА СЪЁМКУ И ПУБЛИКАЦИЮ

Я, _______________________________, телефон _______________,

даю согласие Центру массажа и восстановления «ОРОМ» на съёмку
и публикацию моих фотографий и видеозаписей, сделанных
____________ (дата), в следующих целях:

  ☐ публикации в социальных сетях центра
  ☐ размещение на сайте центра
  ☐ печатные материалы центра

Я уведомлён(а), что:
— могу отозвать согласие в любой момент, написав на +992 93 172 77 77;
— после отзыва материалы удаляются из публикаций центра в течение 10 дней;
— согласие не распространяется на передачу материалов третьим лицам;
— медицинская информация и сведения о моём состоянии не публикуются.

Подпись _______________      Дата _______________
```

**Правила, которые не отменяются согласием:**

- Дети не снимаются и не публикуются ни при каких условиях.
- Не публикуются кадры с обнажением и позы, допускающие двойное прочтение.
- Не публикуется информация о состоянии здоровья клиента, даже с согласия.
- Не публикуются «до / после» на теле.

## Чек-лист материалов о детской программе

- [ ] Нет фотографий, силуэтов и голосов детей.
- [ ] Указано «по направлению врача».
- [ ] Обращение к родителю, не к ребёнку.
- [ ] Шрифт и палитра — общие, без «детского» оформления.
- [ ] Размещение в детских учреждениях согласовано письменно.
- [ ] Нет обещаний медицинского результата.

## Чек-лист перед запуском веб-страницы

- [ ] Одна цель, одна акцентная кнопка.
- [ ] Телефон доступен в один клик с любой страницы.
- [ ] Форма записи работает на телефоне с 3G.
- [ ] Поля формы: имя и телефон обязательны, согласия отдельными чекбоксами.
- [ ] Воскресенье в календаре показано выключенным, а не отсутствующим.
- [ ] Все состояния компонентов реализованы, включая `loading` и `disabled`.
- [ ] Прохождение формы с клавиатуры проверено.
- [ ] Метрики целей настроены.
- [ ] Страница читается при отключённых изображениях.
- [ ] `hreflang` для трёх языков проставлены.

## Чек-лист перед печатью

- [ ] Поля и вылеты соблюдены: 24 мм / 20 мм, вылет 3 мм.
- [ ] 300 dpi в итоговом размере.
- [ ] CMYK, чёрный текст 100 % K.
- [ ] Шрифты встроены или в кривых.
- [ ] Заголовок читается с расстояния, на котором материал будут видеть.
- [ ] Контакты и QR проверены.
- [ ] Пробный оттиск просмотрен до тиража.

## Чек-лист перед выгрузкой видео

Полный список — в [`01-foundations/08-video-and-grading.md`](../01-foundations/08-video-and-grading.md).
Коротко: безопасные поля, субтитры, одинаковый грейд, −14 LUFS,
понятность без звука, логотип не дольше 2 секунд.

## Кто подписывает

| Материал | Согласует |
|---|---|
| Пост, сторис | SMM-менеджер самостоятельно по чек-листу |
| Пост с ценами, корпоративный | руководитель |
| Любой материал о детской программе | руководитель + мастер детской программы |
| Формулировки о противопоказаниях | мастер центра |
| Документы, счета, акты | руководитель |
| Изменение в дизайн-системе | руководитель, с записью в `CHANGELOG.md` |

## Что делать при ошибке в публикации

1. Снять публикацию, если в ней неверные данные о времени, цене или медицинское обещание.
2. Опубликовать исправление тем же форматом, без объяснений в духе «простите,
   нас взломали».
3. Записать причину в заметку к календарю, чтобы не повторить.
4. Если ошибка в дизайн-системе — внести правку в соответствующий файл и
   поднять версию в `CHANGELOG.md`.
