# Форматы и правила публикаций

## Форматы

| Формат | Размер | Где | Безопасное поле |
|---|---|---|---|
| Вертикальный пост | 1080 × 1350 | Instagram, Facebook — основной | 64 px |
| Квадрат | 1080 × 1080 | карусели, сетка профиля | 64 px |
| Сторис / Рилс | 1080 × 1920 | Instagram, TikTok, Shorts | 180 сверху, 320 снизу |
| Обложка рилс | 1080 × 1350 | превью в профиле | смысл в центральном квадрате |
| Горизонталь | 1920 × 1080 | YouTube, экран в холле | 80 px |
| Постер A3 | 297 × 420 мм | подъезды, бизнес-центры, партнёры | 24 мм |
| Аватар | 320 × 320 | профиль | монограмма в круге |

## Три обязательных слоя публикации

У каждой публикации в системе есть три слоя. Публикация без третьего слоя
не выпускается.

1. **Визуал** — раскладка по сетке, токены палитры и типографики.
2. **Текст** — на нужных языках, в тоне из [`06-content/01-voice-and-tone.md`](../06-content/01-voice-and-tone.md).
3. **Действие** — ровно одно: записаться, написать, позвонить, сохранить.

## Композиционные схемы постов

### Схема A — «Тихий заголовок»
Для заявлений о курсе и позиционировании.

```
┌──────────────────────┐  фон: cream
│                      │
│  ВОССТАНОВЛЕНИЕ      │  overline, terra-700, 64px от края
│                      │
│  Курс из десяти      │  display-2, PT Serif 700, forest-800
│  сеансов за три      │
│  недели              │
│                      │
│  ─────────           │  линия terra-500, 80×3px
│                      │
│  Один мастер ведёт   │  body-lg, ink-600
│  курс целиком        │
│                      │
│  [знак]      orom.tj │  caption, ink-400
└──────────────────────┘
```

### Схема B — «Фото и плашка»
Для показа работы мастера.

```
┌──────────────────────┐
│                      │
│      фотография      │  65 % высоты, прижата к верху и краям
│                      │
├──────────────────────┤  плашка forest-800, 35 % высоты
│  Спина к вечеру      │  h2, cream
│  каменная?           │
│  Курс 10 сеансов     │  body, forest-300
│  [Запись в профиле]  │  terra-500
└──────────────────────┘
```

### Схема C — «Сетка слотов»
Главный рабочий формат: заполняет пустые слоты.

```
┌──────────────────────┐  фон: sand-100
│  СВОБОДНО НА НЕДЕЛЕ  │  overline
│                      │
│  Пн  11:00  15:30    │  mono, крупно, чипы slot-free
│  Вт  15:30           │
│  Ср  11:00  14:00    │
│  Чт  15:30  18:30    │
│  Пт  15:30           │
│  Сб  11:00           │
│                      │
│  Запись по ссылке    │
│  в профиле           │
└──────────────────────┘
```

### Схема D — «Карусель»
Разворачивает одну мысль на 4–7 кадров.

| Кадр | Содержание |
|---|---|
| 1 | вопрос или утверждение крупно, без пояснений |
| 2–5 | по одной мысли на кадр, одинаковая раскладка |
| 6 | итог одной фразой |
| 7 | действие: как записаться |

Первый кадр карусели никогда не содержит слова «листай» и стрелку —
это снижает доверие. Если кадр интересен, листают сами.

## Правила

### Можно

- Много воздуха: минимум 64 px от края, в постере — 24 мм.
- Один смысловой акцент на кадр.
- Один акцентный цвет на макет.
- Фото с затемнением под текстом.
- Трёхъязычная подпись в описании поста (визуал — на одном языке).

### Нельзя

- Больше двух гарнитур.
- Текст на пёстром участке фото без подложки.
- Больше трёх блоков текста в одном кадре.
- Эмодзи в первой строке и больше двух на пост.
- Срочность: «успей», «последние места», «только сегодня», таймеры.
- Чужие фото из стоков с «массажным» антуражем: камни, свечи, орхидеи.
- Цены в виде «от 100 с.» — цена курса называется целиком или не называется.
- Фото клиентов без письменного согласия, фото детей — никогда.
- Сравнение «до / после» на теле.
- Медицинские обещания: «вылечим», «избавим от грыжи», «гарантия результата».

## Язык публикаций

| Площадка | Визуал | Описание |
|---|---|---|
| Instagram | русский | RU + TJ, два абзаца |
| TikTok | таджикский | TJ + RU |
| Telegram | русский | RU, при корпоративной теме — RU |
| Facebook | русский | RU + EN для корпоративной аудитории |
| Постеры в БЦ | русский | дескриптор на трёх языках мелко |

Визуал делается **на одном языке** — двуязычный макет перегружается. Второй
и третий язык живут в описании под постом.

## Хештеги

- 5–8 штук, в конце описания, отдельным абзацем.
- Обязательные: `#ором` `#массаждушанбе` `#массажТочикистон`.
- По теме: `#спинаишея` `#восстановление` `#курсмассажа`.
- Запрещены: накрутка, не относящиеся к теме, больше 12 штук.

## Частота

| Формат | Частота |
|---|---|
| Пост в ленте | 3 в неделю |
| Сторис | ежедневно, 2–4 кадра |
| Рилс | 2 в неделю |
| Свободные слоты (схема C) | понедельник и четверг |
| Корпоративный пост | 1 в две недели |

Календарь на четыре недели — [`05-content-calendar.md`](05-content-calendar.md).
