# Движение и анимация

## Принцип

Движение в ОРОМ **объясняет**, а не развлекает. Элемент появляется там, откуда
он логически пришёл, и исчезает туда же. Ничего не прыгает, не пружинит, не мигает.

## Длительности

| Токен | Значение | Что |
|---|---|---|
| `--duration-instant` | 80 мс | смена состояния: наведение, нажатие |
| `--duration-fast` | 160 мс | подсказка, бейдж, переключатель |
| `--duration-base` | 240 мс | выпадающий список, аккордеон, карточка |
| `--duration-slow` | 360 мс | модальное окно, панель записи, лист снизу |
| `--duration-page` | 480 мс | переход между экранами |

Дольше 480 мс в интерфейсе не анимируется ничего. Ожидание перестаёт читаться
как плавность и начинается как тормоз.

## Кривые

| Токен | cubic-bezier | Когда |
|---|---|---|
| `--ease-out` | `(0.22, 1, 0.36, 1)` | появление: элемент входит в кадр |
| `--ease-in` | `(0.64, 0, 0.78, 0)` | исчезновение: элемент уходит |
| `--ease-in-out` | `(0.65, 0, 0.35, 1)` | перемещение в пределах экрана |
| `--ease-linear` | `linear` | только индикатор загрузки и прогресс курса |

**Правило:** появление всегда быстрее исчезновения по ощущению — `ease-out`
на входе, `ease-in` на выходе. Обратное даёт «вязкость».

## Паттерны

| Паттерн | Что происходит |
|---|---|
| **Появление карточки** | `opacity 0→1` + `translateY 8px→0`, 240 мс, `ease-out` |
| **Модальное окно** | затемнение `opacity 0→1` 240 мс; окно `scale .96→1` + `opacity`, 360 мс, `ease-out` |
| **Панель записи (мобильный)** | лист снизу `translateY 100%→0`, 360 мс, `ease-out` |
| **Выбор слота** | заливка чипа 160 мс + галочка `scale .6→1` 160 мс с задержкой 80 мс |
| **Прогресс курса** | закрашивание точки слева направо, 400 мс, `linear`, по одной точке |
| **Подтверждение записи** | галочка рисуется обводкой 480 мс, затем текст `fade-in` 240 мс |
| **Ошибка поля** | подсветка границы 160 мс; **без тряски** — тряска читается как упрёк |
| **Загрузка** | скелетон с мягким пульсом 1600 мс, `ease-in-out`, амплитуда 6 % |

## Скролл

- Параллакс — **не используется**.
- Появление блоков при прокрутке: `opacity` + `translateY 12px`, 320 мс, однократно,
  порог 20 % видимости. Повторная анимация при обратной прокрутке не запускается.
- Закрепление шапки: переход в сжатое состояние за 160 мс после 80 px прокрутки.
- Плавная прокрутка к якорю — 480 мс, `ease-in-out`.

## Анимация логотипа

Единственная разрешённая анимация знака: **последовательная отрисовка дуг**
снизу вверх — линия, внешняя дуга, средняя, терракотовая.

| Параметр | Значение |
|---|---|
| Общая длительность | 1200 мс |
| Задержка между дугами | 160 мс |
| Отрисовка одной дуги | 400 мс, `ease-out`, `stroke-dashoffset` |
| После отрисовки | статика, минимум 1,5 с в кадре |

Запрещено: вращение, пульсация, «дыхание», морфинг в другие формы, вылет букв,
разлетающиеся частицы, блик по логотипу.

## Доступность

Движение уважает настройку системы:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
}
```

При включённой настройке: переходы становятся мгновенной сменой состояния,
скелетоны не пульсируют, автопрокрутка каруселей выключается, анимация
логотипа заменяется статичным знаком.

## Запреты

1. Автовоспроизведение со звуком — никогда.
2. Бесконечные циклические анимации в интерфейсе, кроме индикатора загрузки.
3. Мигание и стробоскоп — чаще 3 раз в секунду опасно и запрещено стандартом.
4. Анимированный фон под текстом.
5. Пружина и отскок (`bounce`, `elastic`) — противоречат спокойному характеру бренда.
6. Движение, которое нельзя остановить или пропустить.
7. Анимация, задерживающая показ содержимого дольше 480 мс.
