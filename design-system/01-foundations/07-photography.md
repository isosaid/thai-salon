# Фотография и генеративные изображения

## Принцип

Фотография в ОРОМ показывает **работу и человека**, а не антураж.
Руки мастера, сосредоточенное лицо, свет из окна на простыне, чистое полотенце,
лицо клиента после сеанса. Не свечи, не камни, не орхидеи, не лепестки на воде.

## Технические параметры съёмки

| Параметр | Значение |
|---|---|
| Соотношение | 3:2 и 4:5 для ленты, 9:16 для сторис |
| Свет | мягкий естественный, один источник, окно слева или справа |
| Время съёмки | 1–2 часа до заката: тёплый длинный свет |
| Температура | 4800–5600 K, слегка тёплая |
| Диафрагма | f/2.0–f/2.8 для портрета, f/4–f/5.6 для интерьера |
| Фокусное | 35 мм для сцены, 50–85 мм для портрета и рук |
| Точка съёмки | уровень глаз сидящего человека, не сверху |
| Экспозиция | +1/3 EV, светлая картинка, никаких провалов в тенях |

## Палитра кадра

Кадр должен попадать в палитру бренда **на съёмочной площадке**, а не в обработке:

- бельё и полотенца — некрашеный лён, молочный, песочный;
- стены — тёплый светлый, кремовый;
- акцент в кадре — один тёплый терракотовый предмет (плед, керамика, кафельная деталь);
- зелень — живое растение в кадре, не более одного;
- **никакого** холодного белого, синей подсветки, хромированного металла, неона.

## Что снимаем

### Обязательный минимум съёмки

| Кадр | Ориентация | Зачем |
|---|---|---|
| Руки мастера на спине, крупно | горизонт | главный образ бренда, обложки |
| Портрет каждого мастера | вертикаль 4:5 | карточки мастеров — закрывает перекос загрузки кабинетов |
| Кабинет без людей, свет из окна | горизонт | страница «О центре», карты |
| Кабинет с готовым столом | вертикаль | сторис «свободно сегодня» |
| Клиент одевается после сеанса, спокойное лицо | 4:5 | «результат», отзывы |
| Администратор за стойкой, запись в журнал | горизонт | «как записаться» |
| Детали: сложенные полотенца, масло, часы на стене | квадрат | заполнение сетки профиля |
| Вход в центр с улицы | вертикаль | «как нас найти» |

### Правила по людям в кадре

- **Согласие письменно.** Фото клиента публикуется только с подписанным согласием.
  Форма — в [`07-governance/01-checklists.md`](../07-governance/01-checklists.md).
- **Дети не публикуются.** Детская программа показывается через кабинет, мастера,
  руки — но без лиц и фигур детей.
- **Тело закрыто.** Видна спина, плечи, шея, стопы. Не публикуется: ягодицы,
  грудь, бельё, любая поза, допускающая двойное прочтение.
- **Лицо клиента не показывает боль.** Либо спокойствие, либо кадр без лица.
- **Мастер в форме.** Одинаковая одежда, чистые руки, короткие ногти, без украшений.

## Обработка

| Параметр | Направление |
|---|---|
| Контраст | мягкий, S-кривая без крайних точек |
| Тени | приподняты, не чёрные: минимум `#2A2420`, не `#000` |
| Света | не выбиты, кожа держит детали |
| Насыщенность | −5…−10 от исходной, кроме терракотового акцента |
| Тон | тёплый: +4 в тенях, +2 в светах по жёлто-красному |
| Зерно | лёгкое, органическое, 8–12 % на 100 % просмотре |
| Резкость | умеренная, кожа не «хрустит» |

**Запрещено:** HDR, осветление зубов и белков, пластика тела, гладкая «пластиковая» кожа,
синие тени, кросс-процесс, виньетка сильнее 10 %, зеркальное отражение кадра
с текстом в нём.

## Генеративные изображения

Когда реальной съёмки нет, допускается генерация — **только для фона, текстуры,
интерьера и абстракции**. Генерировать лица мастеров, «клиентов» и «результаты»
запрещено: это обман аудитории и риск для репутации центра.

### Промпты

Каждый промпт дан на английском (так модели работают точнее) с русским переводом ниже.

**1. Кабинет, пустой, тёплый свет**

```
Empty massage therapy room at golden hour, soft window light from the left,
cream plaster walls, natural linen sheets on a wooden treatment table, one terracotta
ceramic vessel, a single green plant, warm muted palette of deep green cream and
terracotta, 35mm, f/4, photographic, no people, calm and clean, soft shadows,
slight film grain --ar 3:2
```
> Пустой массажный кабинет в час золотого света, мягкий свет из окна слева, кремовые
> оштукатуренные стены, натуральное льняное бельё на деревянном массажном столе, один
> терракотовый керамический сосуд, одно зелёное растение, тёплая приглушённая палитра
> из глубокого зелёного, кремового и терракоты, 35 мм, f/4, фотографично, без людей,
> спокойно и чисто, мягкие тени, лёгкое плёночное зерно, соотношение 3:2.

**2. Текстура льна для фона постера**

```
Close-up texture of undyed natural linen fabric, soft folds, warm sand color,
raking light from one side, extremely shallow depth, minimal, no pattern, no logo,
photographic macro, neutral warm tone --ar 1:1
```
> Макро-текстура некрашеного натурального льна, мягкие складки, тёплый песочный цвет,
> скользящий свет с одной стороны, очень малая глубина резкости, минимализм, без узора,
> без логотипа, фотографическое макро, нейтрально-тёплый тон, соотношение 1:1.

**3. Абстрактный фон «восход» по мотивам знака**

```
Minimal abstract composition, three concentric arcs rising above a horizontal line,
deep forest green and one terracotta arc, flat vector, warm cream background,
generous negative space, no text, no gradient mesh, editorial poster aesthetic --ar 4:5
```
> Минималистичная абстрактная композиция, три концентрические дуги над горизонтальной
> линией, глубокий лесной зелёный и одна терракотовая дуга, плоский вектор, тёплый
> кремовый фон, много свободного пространства, без текста, без градиентных сеток,
> эстетика издательского постера, соотношение 4:5.

**4. Детали: сложенные полотенца**

```
Stack of folded cream and sand colored towels on a wooden shelf, warm diffused light,
shallow depth of field, calm minimal interior, deep green wall in background out of focus,
photographic, no people, no branding --ar 1:1
```
> Стопка сложенных полотенец кремового и песочного цвета на деревянной полке, тёплый
> рассеянный свет, малая глубина резкости, спокойный минималистичный интерьер, глубокая
> зелёная стена на расфокусированном фоне, фотографично, без людей, без брендинга,
> соотношение 1:1.

**5. Фон для сторис с местом под текст**

```
Soft vertical gradient background from warm cream to pale sand, subtle paper grain,
one blurred terracotta shape in the lower third, large empty space in the upper two
thirds for typography, no objects, no people, flat and calm --ar 9:16
```
> Мягкий вертикальный градиентный фон от тёплого кремового к бледно-песочному, едва
> заметное зерно бумаги, одна размытая терракотовая форма в нижней трети, большое пустое
> пространство в верхних двух третях под типографику, без предметов, без людей, плоско
> и спокойно, соотношение 9:16.

### Негативные слова для любого промпта

```
--no people faces, hands, candles, hot stones, orchid, lotus, rose petals, bamboo,
neon, blue light, chrome, glossy skin, text, watermark, logo, HDR, oversaturated
```
> Исключить: лица людей, руки, свечи, горячие камни, орхидея, лотос, лепестки роз,
> бамбук, неон, синий свет, хром, глянцевая кожа, текст, водяной знак, логотип,
> HDR, пересыщенность.

### Обязательная маркировка

Любое сгенерированное изображение, опубликованное от имени центра, помечается
в описании публикации: `Изображение создано нейросетью` / `Тасвир тавассути
нейрошабака сохта шудааст` / `AI-generated image`. Это не мелкий шрифт в углу,
а строка в тексте поста.
