# Видео, монтаж и цветокоррекция

Раздел для видеографа и колориста. Задаёт параметры съёмки, монтажа, грейда
и выгрузки, чтобы любой ролик центра читался как один бренд.

## Форматы и мастер-настройки

| Площадка | Разрешение | Кадр/с | Длительность | Контейнер |
|---|---|---|---|---|
| Reels / Shorts / TikTok | 1080 × 1920 | 30 | 15–45 с | H.264, 12–16 Мбит/с |
| Пост-видео в ленте | 1080 × 1350 | 30 | 15–60 с | H.264, 12 Мбит/с |
| YouTube, сайт | 1920 × 1080 | 25 или 30 | 1–3 мин | H.264, 20 Мбит/с |
| Экран в холле центра | 1920 × 1080 | 25 | петля 2–4 мин | H.264, 16 Мбит/с, без звука |
| Мастер-архив | 3840 × 2160 | как снято | — | ProRes 422 HQ |

**Съёмка:** снимать в 4K, монтировать в 4K, выгружать в HD с даунскейлом —
это даёт запас на кадрирование вертикали из горизонтали и чистую картинку после сжатия.

| Параметр съёмки | Значение |
|---|---|
| Выдержка | 1/60 при 30 к/с, 1/50 при 25 к/с (правило 180°) |
| ISO | базовое ISO камеры, не выше 1600 |
| Профиль | Log (S-Log3 / V-Log / C-Log3) или HLG; при съёмке на телефон — ProRes Log либо обычный профиль с выключенной «резкостью» |
| Баланс белого | ручной, 5200 K, один на всю смену — не авто |
| Движение камеры | только медленное: slider, gimbal на минимальной скорости, статика на штативе |
| Запрещено | зум объективом, дрожащая «репортажная» камера, резкий whip-pan, дрон внутри помещения |

## Монтажный ритм

Бренд спокойный — монтаж это обязан отражать.

| Параметр | Значение |
|---|---|
| Средняя длина плана | 2,5–4 с (в рилс — 1,5–2,5 с) |
| Минимальная длина плана | 0,8 с; короче — только в финальной сборке-перечислении |
| Тип склейки | прямая склейка, реже — mix 8–12 кадров |
| Запрещённые переходы | zoom-transition, glitch, whip-pan, «бабочка», шторки, 3D-кубы |
| Начало ролика | первые 1,5 с — главный кадр, без логотипа и титров |
| Логотип | только в конце, 1,5–2 с, на `cream` или затемнённом кадре |

**Структура рилс 20–30 секунд**

```
0,0–1,5 с   крючок: руки мастера крупно, звук массажа без музыки
1,5–4,0 с   проблема одной строкой: титр «Шея к вечеру каменная?»
4,0–14,0 с  суть: 3–4 плана работы мастера, спокойный темп
14,0–20,0 с результат: клиент одевается, спокойное лицо, титр «Курс 10 сеансов»
20,0–24,0 с действие: «Запись по ссылке в профиле» + слоты мелко
24,0–26,0 с лого на cream, 1,5 с, без анимации входа
```

## Титры

| Параметр | Значение |
|---|---|
| Шрифт | Inter SemiBold 600 (не PT Serif — засечки дрожат при сжатии) |
| Кегль | 56–72 px при 1080 × 1920 |
| Интерлиньяж | 1,2 |
| Цвет | `#F4EDE3` на затемнении или `#1A1714` на светлом |
| Подложка | плашка `forest-800` 85 % или градиент-затемнение снизу |
| Положение | нижняя треть, но **выше 320 px** от низа кадра |
| Строк | не более двух, в строке не более 32 знаков |
| Появление | fade 6 кадров, без «печатной машинки», без вылета по буквам |
| Длительность | минимум 1,2 с + 0,25 с на каждое слово |

**Субтитры** обязательны для всех роликов: 85 % просмотров идёт без звука.
Язык субтитров — тот же, что в озвучке; второй язык даётся отдельной версией ролика,
а не вторым рядом субтитров в том же кадре.

## Цветокоррекция

### Пайплайн

```
1. Нормализация      → IDT исходника в рабочее пространство (ACEScct или DaVinci WG/Intermediate)
2. Балансировка      → экспозиция и баланс белого по карте, план к плану
3. Первичка          → lift/gamma/gain по колесу, контраст по кривой
4. Вторичка          → кожа (qualifier), бельё, зелень, терракотовый акцент
5. Look              → фирменная кривая + сплит-тонирование
6. Финал             → зерно, виньетка, резкость под площадку, ODT
```

### Фирменный look: «тёплый лён»

| Шаг | Настройка |
|---|---|
| Lift | +0,02 по яркости, сдвиг в тёплый: R +0,015, G +0,005, B −0,01 |
| Gamma | нейтральная, контраст набирается кривой |
| Gain | −0,02, чтобы света не звенели; B −0,015 |
| Кривая | мягкая S: точка 0,25 → 0,22 и точка 0,75 → 0,78 |
| Насыщенность | 92 % от исходной |
| Сплит-тонирование | тени → зелёно-жёлтый (hue 85°, sat 8 %), света → оранжевый (hue 35°, sat 6 %) |
| Hue vs Sat | зелёный −12 %, голубой −35 %, оранжевый +4 % |
| Hue vs Hue | голубой → увести на 8° в циан, чтобы холодные пятна не спорили с палитрой |
| Midtone detail | −8 (кожа мягче) |
| Зерно | Film grain 16 mm, 8–10 % |

### Контрольные точки по скопам

| Что | Где должно быть |
|---|---|
| Чёрная точка | 64–96 в 10-bit (не 0) — тени открытые, не «в пол» |
| Белая точка | 900–960, никогда 1023 — бельё держит фактуру |
| Кожа (светлый тон) | 55–70 IRE на Parade |
| Кожа на Vectorscope | строго вдоль линии skin tone, вектор 10–20 % длины |
| Зелёный канал | не доминирует в светах: G не выше R в бельё |
| Общий тренд Parade | R ≥ G > B во всём диапазоне — это и есть «тёплый» |

### Что нельзя в грейде

- Синие и бирюзовые тени (teal & orange) — прямое противоречие палитре.
- Чёрные провалы до нуля: бренд не делает драматичную картинку.
- Пересветы на белье и стенах — пропадает фактура, главный материал бренда.
- Кожа с розовым или жёлтым уклоном от линии skin tone.
- Разный грейд у планов внутри одного ролика.
- Автоматический LUT «cinematic» поверх Log без балансировки.

### LUT

Фирменный look выдаётся как **два** файла:

| Файл | Назначение |
|---|---|
| `OROM_Linen_Rec709_v1.cube` (33×33×33) | финальный look от нормализованного Rec.709 |
| `OROM_Linen_Monitor_v1.cube` | монитор-LUT на площадке, чтобы оператор видел результат |

LUT применяется **после** балансировки, а не вместо неё. LUT на несбалансированный
материал — главная причина, почему ролики центра не похожи друг на друга.

## Звук

| Параметр | Значение |
|---|---|
| Громкость мастера | −14 LUFS интегрально, пик не выше −1 dBTP |
| Музыка | минималистичная, инструментальная, 60–80 BPM, без вокала и без ударных |
| Громкость музыки под голосом | −18…−22 dB от голоса |
| Естественный звук | обязателен: ткань, масло, дыхание, шум улицы за окном |
| Запрещено | трендовые треки с вокалом, звуки уведомлений, «вжух»-эффекты, автотюн |

Первые 1,5 секунды ролика идут **на естественном звуке без музыки** — это удерживает
внимание сильнее любого трека.

## Чек-лист перед выгрузкой

- [ ] Безопасные поля: ничего важного в нижних 320 px и верхних 180 px вертикали.
- [ ] Субтитры есть, проверены на опечатки, не выходят за кадр на трёх языках.
- [ ] Грейд одинаков во всех планах, проверено переключением между первым и последним.
- [ ] Чёрная точка не в нуле, белая не в 1023 — проверено по Parade.
- [ ] Кожа на линии skin tone — проверено по Vectorscope.
- [ ] Звук −14 LUFS, пики ниже −1 dBTP.
- [ ] Ролик понятен без звука.
- [ ] Логотип в конце не дольше 2 с и не анимирован вылетом.
- [ ] Мастер-файл в ProRes сохранён в архив, имя по шаблону
      `OROM_YYYY-MM-DD_тема_формат_v01`.
- [ ] Если использовано генеративное видео — в описании есть маркировка.
