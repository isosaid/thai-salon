# ОРОМ — дизайн-система

![Логотип ОРОМ](assets/logo-lockup.svg)

Единая визуальная и смысловая система центра курсового массажа и восстановления **ОРОМ**
(тадж. *ором* — покой, умиротворение). Система собрана на основе анализа операционной
учётной книги центра (запись на приём, учёт клиентов, график загрузки за месяц) и предназначена
для производства:

- **веб-платформы** — сайт, онлайн-запись, личный кабинет клиента, админ-панель;
- **контента для соцсетей** — постеры, посты, сторис, рилс, видео;
- **документов** — сертификаты, карты курса, корпоративные предложения, отчёты, акты.

Система трёхъязычная: **русский / тоҷикӣ / English**.

## Три правила, которые важнее остальных

1. **Курс, а не сеанс.** Продукт центра — курс из 10 сеансов, а не одна процедура.
   Любой макет, пост и экран говорит о курсе и о результате к его концу.
2. **Спокойствие важнее яркости.** Воздух, глубокий зелёный, один тёплый акцент.
   Если макет кричит — он не наш.
3. **Три языка равноправны.** Таджикский не перевод-приписка, а полноценная версия.
   Макет проверяется на самой длинной строке из трёх языков.
