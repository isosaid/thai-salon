Импорт в таблицу

Открыть таблицу салона

  1. Откройте таблицу по ссылке выше.
  2. Файл → Импортировать → Загрузка → выберите скачанный CSV.
  3. Место импорта: «Заменить данные на текущем листе» либо «Вставить новые листы».
  4. Тип разделителя: «Другой» → точка с запятой.
  5. Снимите «Преобразовывать текст в числа и даты», чтобы телефоны не потеряли «+992».
Автоматическая запись в таблицу пока не настроена. Чтобы кабинет сам писал записи в Google Sheets, без скачивания файлов, в настройках claude.ai нужно подключить коннектор Google Sheets. После этого кабинет получает доступ к таблице от вашего имени и обновляет её при каждой новой записи.
