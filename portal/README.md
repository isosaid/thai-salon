# Веб-кабинет

Одна самодостаточная HTML-страница. Публикуется как Artifact на claude.ai,
данные живут в базе артефакта.

## Публикация

Страница объявляет три runtime-возможности:

```json
{
  "db": { "rules": [
    { "path": "",         "read": "interact", "write": "interact" },
    { "path": "settings", "read": "interact", "write": "admin" },
    { "path": "clients",  "read": "interact", "write": "interact" }
  ]},
  "user": { "scopes": ["profile"] },
  "downloads": true
}
```

- `db` — расписание и клиенты, общие для всех, кто открыл страницу.
- `user` — кто вошёл и какой у него уровень доступа.
- `downloads` — выгрузка CSV.

Первый кадр страницы рисуется до ответа базы, поэтому в нём стоит оформленное
пустое состояние, а не пустой экран. Если база недоступна, страница говорит
об этом прямо и не притворяется рабочей.

## Засев данных

Файлы из [`data/`](data/) загружаются в базу после публикации — по документу
на файл: `settings/center`, `clients/<группа>`, `days/<дата>`.

## Что страница умеет

| Раздел | Действия |
|---|---|
| Расписание | день по кабинетам и слотам, запись в свободный слот, освобождение занятого |
| График месяца | разворот «день × кабинет × слот» как на листе «График», счётчик рабочих дней, итоги по слотам |
| Запись | курс из 10 сеансов в одно время с пропуском воскресений и проверкой занятости |
| Клиенты | поиск, фильтр по группам, правка карточек, добавление и удаление, подсветка карточек без телефона |
| Загрузка | показатели и столбцы по слотам и кабинетам, считаются из живой базы |
| Экспорт | CSV расписания и клиентов |

## Правка карточек клиента

Карточка правится прямо в таблице: ФИО, пометка, телефон, даты курса и группа.
Телефон при сохранении приводится к формату `+992 XXX XX XX XX`; если цифр
не девять, значение сохраняется как есть и помечается к проверке.

Смена группы выполняется двумя записями: карточка убирается из прежней группы
и добавляется в новую. Счётчики группы — число клиентов, сумма сеансов,
сколько карточек с телефоном — пересчитываются при каждой правке.

Удаление карточки не трогает записи в расписании: проведённые сеансы остаются.

## Ограничения среды

Страница работает в песочнице артефакта: нет печати, нет встроенных iframe,
нет системных диалогов, ссылки открываются в новой вкладке. Выгрузка файлов
идёт только через возможность `downloads` — обычная ссылка со скачиванием
в этой среде не работает.
