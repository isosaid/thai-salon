# Кабинет салона на Google Sheets

> В публичной версии репозитория нет файлов `Data.gs` и `Staff.gs`: первый
> содержит карточки клиентов с телефонами, второй — логины и хеши паролей
> сотрудников. Их структура показана в `Data.example.gs` и `Staff.example.gs`.
> Настоящий `Data.gs` собирает `import/reimport.py` из учётной книги,
> а сотрудников можно завести через меню «Салон → Добавить сотрудника».

База данных — ваша Google-таблица. Вход с паролями, расписание, запись
и карточки клиентов работают через Google Apps Script внутри этой же таблицы.

## Почему вход здесь настоящий

Скрипт выполняется **на стороне Google**, под вашей учётной записью.
Браузер сотрудника не получает доступа к таблице: он вызывает только функции
скрипта, и каждая проверяет сессию. Пароли хранятся солёными хешами —
12 000 проходов SHA-256 на каждый. Восстановить пароль из хеша нельзя,
можно только задать новый.

Главное следствие: **таблицу сотрудникам отдавать не нужно.** Они работают
через сайт и никогда не видят ни листов, ни хешей, ни чужих данных сверх
своей роли.

## Роли

| Роль | Расписание | Запись и освобождение слотов | Карточки клиентов | Удаление карточек |
|---|---|---|---|---|
| `владелец` | да | да | да | да |
| `администратор` | да | да | да | да |
| `мастер` | да | да | да | нет |
| `просмотр` | да | нет | не видит | нет |

Роль пишется строчными буквами в листе «Сотрудники», колонка «Роль».

## Установка

### 1. Скрипт

**Расширения → Apps Script.** В открывшемся редакторе вставьте три файла:

1. Файл `Код.gs` — выделите всё и замените на [`Code.gs`](Code.gs).
2. **+** рядом с «Файлы» → **Скрипт** → имя `Data` → вставьте [`Data.gs`](Data.gs).
3. **+** рядом с «Файлы» → **Скрипт** → имя `Staff` → вставьте [`Staff.gs`](Staff.gs).
4. **+** рядом с «Файлы» → **HTML** → имя `Index` → вставьте [`Index.html`](Index.html).

Сохраните (Ctrl+S) и закройте редактор.

### 2. Данные и служебные листы

Обновите таблицу — в меню появится пункт **«Салон»**. Нажмите по очереди:

1. **Салон → Загрузить данные из книги** — заполнит листы `Клиенты` (437 строк),
   `Расписание` (558 строк) и `Настройки`. Всё записывается текстом, поэтому
   телефоны сохраняют `+992`, а даты не переворачиваются.
2. **Салон → Создать недостающие листы** — появятся `Сотрудники`,
   `Сессии` (скрытый) и `Журнал`.

При первом запуске Google спросит разрешения — это нормально: скрипт просит
доступ к своей же таблице. Нажмите «Разрешить».

Файл `Data.gs` нужен только для этой загрузки. После неё его можно удалить
из проекта: кабинет работает с листами таблицы, а не с ним.

### 3. Сотрудники

Два пути на выбор.

**Быстрый — подготовленные записи.** `Staff.gs` содержит пять готовых
учётных записей с логинами и уже посчитанными хешами паролей:

| Кто | Логин | Роль | Кабинет |
|---|---|---|---|
| Саидова Нигина | `firuza@salon.tj` | мастер | Ели |
| Администратор салона | `admin@salon.tj` | администратор | — |
| Мастер кабинета Нам | `nam@salon.tj` | мастер | Нам |
| Мастер кабинета НОЙ | `noy@salon.tj` | мастер | НОЙ |
| Владелец салона | `owner@salon.tj` | владелец | — |

Нажмите **Салон → Завести подготовленных сотрудников** — все пять строк
запишутся сразу, без вопросов. Пароли переданы отдельно; в таблице их нет,
только хеши.

Почта здесь — только логин: писем скрипт не шлёт, заводить ящики не нужно.
Хотите настоящие адреса — поправьте их потом прямо в листе «Сотрудники»,
пароли от этого не изменятся.

**Обычный — завести вручную.** **Салон → Добавить сотрудника**: скрипт
спросит почту, ФИО, роль, кабинет и пароль. Например, для Фирузы: почта,
«Саидова Нигина», роль `мастер`, кабинет `Ели`, пароль не короче 8 знаков.

`Staff.gs`, как и `Data.gs`, одноразовый — после заведения сотрудников
удалите его из проекта.

Остальные пункты меню: **Задать пароль сотруднику** (если забыл),
**Отключить сотрудника** (закрывает доступ и сбрасывает его сессии).

### 4. Публикация сайта

В редакторе скрипта: **Начать развёртывание → Новое развёртывание** →
шестерёнка → **Веб-приложение**, затем:

| Поле | Значение |
|---|---|
| Описание | Кабинет салона |
| Запуск от имени | **Я** (владелец таблицы) |
| У кого есть доступ | **У всех, у кого есть ссылка** |

Нажмите «Развернуть» и скопируйте URL — это и есть адрес кабинета.
Раздайте его сотрудникам.

«У всех, у кого есть ссылка» означает, что страницу входа откроет любой,
кто знает адрес. Данных без логина и пароля он не увидит: каждая функция
проверяет сессию.

После правок кода повторяйте **Начать развёртывание → Управление
развёртываниями → Изменить → Версия: Новая**, иначе сайт останется на старой версии.

## Что умеет кабинет

| Раздел | Содержание |
|---|---|
| Расписание | день по трём кабинетам и шести слотам, запись и освобождение |
| График месяца | разворот «день × кабинет × слот» как на листе «График» в книге |
| Запись | курс из 10 сеансов в одно время, воскресенья пропускаются, занятые дни видны заранее |
| Клиенты | поиск, фильтр по группам, правка карточек, добавление и удаление |
| Загрузка | показатели и столбцы по слотам и кабинетам, считаются из таблицы |

Сотрудник может сменить себе пароль прямо в кабинете — кнопка в шапке.

## Новый месяц

**Салон → Добавить месяц в расписание**, формат `ГГГГ-ММ`.
Скрипт добавит 18 строк на каждый день месяца и отметит воскресенья
выходными. Уже существующие дни не трогаются.

## Порядок работы с таблицей

- Сотрудникам доступ к таблице **не давайте** — только ссылку на сайт.
- Лист «Сессии» скрыт намеренно: в нём токены входа. Чтобы разом выбросить
  всех из кабинета, удалите в нём все строки кроме шапки.
- Лист «Журнал» пишет, кто и что сделал: вход, запись, освобождение слота,
  правку и удаление карточек. Полезно при разборе спорных ситуаций.
- Руками в «Расписании» лучше не править: кабинет пишет те же строки,
  и одновременная правка приведёт к расхождению. Исключение — массовые
  исправления, когда в кабинете никто не работает.

## Ограничения, о которых стоит знать

- **Вход занимает секунду-полторы.** Это намеренно: медленный хеш и пауза
  в 400 мс делают перебор паролей бессмысленным.
- **Квоты Apps Script.** Для бесплатного аккаунта Google — около 90 минут
  выполнения скрипта в сутки. Салону на 6 слотов в день этого хватает
  с большим запасом, но тысячи одновременных пользователей такая схема
  не держит.
- **Пароль восстановить нельзя**, только задать новый через меню.
- **Двухфакторной проверки нет.** Если она нужна, вход делается через
  аккаунты Google: тогда пароли вообще не хранятся, а скрипт сверяет
  `Session.getActiveUser().getEmail()` с листом «Сотрудники».
- **Телефоны клиентов — персональные данные.** Таблицу не публикуйте
  и доступ к ней не раздавайте.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| «Нет листа «…»» | лист назван иначе; переименуйте точно как в инструкции |
| «Сессия истекла» | прошло 12 часов; войдите заново |
| «Неверная почта или пароль» | один и тот же ответ на обе ошибки — так задумано |
| Сайт открылся старым | после правок нужно новое развёртывание, см. шаг 5 |
| Телефоны без «+992» | данные вносили не через «Загрузить данные из книги», а импортом CSV без снятой галочки преобразования текста |
| «menuImportData не найдена» | не вставлен файл `Data.gs`, см. шаг 1 |
| «menuSeedStaff не найдена» | не вставлен файл `Staff.gs`, см. шаг 1 |
| «Нет листа «Сотрудники»» | сначала «Создать недостающие листы», потом заводить сотрудников |
