# Импорт из учётной книги

`reimport.py` читает книгу Excel и собирает из неё документы базы,
`Data.gs` для Apps Script и выгрузки CSV. `audit.py` сверяет книгу
саму с собой: сопоставляет имена в расписании с карточками клиентов
и сравнивает счётчики по кабинетам с фактической сеткой.

## Перед запуском

В публичной версии названия групп и имена в примерах заменены
вымышленными. Под свою книгу поправьте список `GK` в `reimport.py`
и `audit.py` — он должен совпадать с заголовками групп на листе
«Учёт клиентов»:

```python
GK = [('Альфа Групп', 'g_alfa', 'Альфа Групп', 'corporate', None),
      ...]
#      ^ как написано в книге   ^ id   ^ как показывать   ^ сегмент  ^ размер пакета
```

Так же проверьте имена листов: скрипт ожидает «Учёт клиентов …»,
«График …» и шесть слотов 11:00–18:30 в трёх кабинетах.

## Запуск

```bash
python3 audit.py      # сверка: несопоставленные имена и расхождения счётчиков
python3 reimport.py   # сборка документов базы, Data.gs и CSV
```

Что делает нормализация имён: убирает хвостовые пробелы, выносит пометку
группы из поля ФИО в отдельное поле, присваивает карточкам устойчивые
идентификаторы и связывает каждую ячейку расписания с карточкой.
Телефоны приводятся к формату `+992 XXX XX XX XX`; номера короче девяти
цифр не достраиваются, а помечаются к проверке.
