# Оздоровительный тайский салон · Душанбе

Проект салона: фирменный стиль, дизайн-система и рабочий веб-кабинет
с расписанием, записью клиентов и учётом курсов.

> **Клиентских данных в этом репозитории нет.** Карточки клиентов, телефоны
> и заполненное расписание исключены из публикации: это персональные данные
> живых людей. Вместо них лежат обезличенные образцы
> (`sheets-app/data/*.sample.csv`, `Data.example.gs`, `Staff.example.gs`),
> структура в них та же. Настоящие данные собираются скриптом из учётной
> книги — см. «Импорт из Excel».

## Кабинет на базе артефакта

Страница [`portal/portal.html`](portal/portal.html) публикуется как Artifact на claude.ai
и работает с его базой данных. Вход — по аккаунту claude.ai, роль определяется уровнем
доступа к странице: владелец и редакторы меняют расписание, остальные сотрудники
записывают клиентов, кому открыт только просмотр — видят данные без права правки.

Пять разделов: расписание дня, график месяца, запись на курс, база клиентов,
загрузка и экспорт.

### Модель данных

| Коллекция | Документы | Содержимое |
|---|---|---|
| `settings` | `center` | слоты, кабинеты, программы, базовые показатели |
| `clients` | 7 документов по группам | карточки клиентов: ФИО, группа, счётчики по кабинетам, даты курса, телефон |
| `days` | по документу на дату | сетка 3 кабинета × 6 слотов на день |

Такая разбивка повторяет структуру учётной книги и укладывается в 39 документов
вместо 700 с лишним, если бы каждая запись была отдельным документом.

### Права доступа

```
корень      чтение interact · запись interact
settings    чтение interact · запись admin
clients     чтение interact · запись interact
```

Телефоны клиентов не отдаются тем, кому страница открыта только на просмотр —
проверено чтением базы на пониженном уровне доступа.

## Операционная модель салона

| Параметр | Значение |
|---|---|
| Кабинетов | 3 — Нам, Ели, НОЙ |
| Слотов в день | 6 — 11:00, 12:30, 14:00, 15:30, 17:00, 18:30 |
| Длительность сеанса | 1 ч 30 мин |
| Рабочих дней в месяце | 27, воскресенье — выходной |
| Курс | 10 сеансов в одно и то же время |
| Ёмкость месяца | 486 сеансов |

## Импорт из Excel

```bash
python3 import/audit.py      # сверка книги: имена, группы, счётчики
python3 import/reimport.py   # формирование документов базы и CSV
```

Импорт нормализует имена: убирает хвостовые пробелы, выносит пометки группы
из поля ФИО в отдельное поле (`Бобоев Сино "Бета"` → имя + пометка),
присваивает карточкам устойчивые идентификаторы и связывает каждую ячейку
расписания с карточкой клиента.

Телефоны приводятся к формату книги — `+992 XXX XX XX XX`, код оператора
три цифры. Номера, в которых в книге меньше девяти цифр, не достраиваются:
они сохраняются как есть и помечаются `telCheck` — в кабинете у них стоит
метка «проверить».

Контроль целостности на октябре 2026: 237 ячеек сетки, все связаны с карточками,
несопоставленных имён нет; у всех 29 активных клиентов счётчики по кабинетам
в карточке совпадают с фактической сеткой.

## Что не доделано

- **Связь двух кабинетов.** Версия на Sheets и версия на артефакте ведут
  свои копии данных; синхронизации между ними нет. Рабочей стоит сделать одну.
- **Дизайн-система названа ОРОМ.** Она собрана до выбора названия и требует
  замены имени на описательное — порядок замены описан
  в [`design-system/00-start/03-rename-brand.md`](design-system/00-start/03-rename-brand.md).
- **Нет фотосъёмки.** Фотостиль описан, кадры не сняты.
